如何工作

简单四步，开启智能协作

1

创建任务

协作者在看板创建任务，填写问题描述、技术栈和期望交付物。

2

任务下发

任务通过 OpenKit 协议实时发送给 Claude Code。

3

自动执行

Claude Code 在本地工作目录执行任务，生成代码、方案或审查报告。

4

结果返回

执行结果（MR 链接、文档等）自动返回看板，任务状态更新为已完成。
