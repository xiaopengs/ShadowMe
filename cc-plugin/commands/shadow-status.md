# Shadow Status

查看当前正在执行的任务状态和影子分身的连接状态。

## 用法

```
/shadow-status
/shadow-status <task-id>
```

## 执行流程

### 1. 检查连接状态
```bash
# 读取配置文件
cat ~/.shadowme/config 2>/dev/null

# 测试API连接
${CLAUDE_PLUGIN_ROOT}/scripts/shadowme-api.sh GET "/api/shadow/status"
```

### 2. 获取当前任务信息
```bash
# 读取当前任务记录
cat ~/.shadowme/current-task 2>/dev/null

# 获取任务详情（如有）
${CLAUDE_PLUGIN_ROOT}/scripts/shadowme-api.sh GET "/api/tasks/${TASK_ID}"
```

## 快速命令

| 命令 | 说明 |
|------|------|
| `/shadow-status` | 查看当前状态 |
| `/shadow-poll` | 拉取新任务 |
| `/shadow-log <msg>` | 发送进度日志 |

## 状态码说明

- `💤 空闲` - 未领取任何任务
- `🔄 执行中` - 正在执行任务
- `⏸️ 已暂停` - 任务已暂停
- `❌ 错误` - 连接异常
